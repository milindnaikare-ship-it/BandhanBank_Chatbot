In The Room

Five-minute demo script

  1. Open the site — point out the native-branded widget and "Be our customer!" ribbon.
  2. Ask "Compare your savings accounts" — show the grounded, table-formatted answer.
  3. Switch to Hindi or Bengali and ask again — same quality, in-language.
  4. Use voice — speak a query and let the assistant read the answer aloud.
  5. Log in as an existing customer, open Self-service Banking.
  6. Run a Fund Transfer: payee → summary → OTP → UTR reference (note the masking).
  7. Open an FD: live rates, maturity preview, instant booking.
  8. Trigger feedback / escalation to show the human hand-off.
